## 插件推荐

**Excalidraw**
绘画

**Style Settings**

**Github Copilot**

**Clear Unused Images**
点击侧边栏按钮，移除笔记中未使用的图片附件，实现仓库“瘦身”，保持Obsidian界面清爽。

**Commander**
自定义Obsidian界面快捷按钮，比如快速分屏、置顶等功能，可自由选择按钮添加位置并自定义功能动作。

**Deep Planner**
可设置快捷键（如Ctrl+T），一键插入当前时间戳，搭配Deep Planner插件，能完善时间轴的记录功能。

**Time Stampler**
可设置快捷键（如Ctrl+T），一键插入当前时间戳。

**File Explorer Note Count**
在文件管理器中显示各文件夹内的笔记数量。

**Hover Editor**
按住 `Ctrl` 点击笔记内的链接，可预览目标笔记；支持“钉住”功能，生成悬浮笔记。

**Journals**
日记管理插件，右侧侧边栏会显示日历，点击日期可快速跳转至对应的日、周、月笔记页面。

**Pandoc**
持将笔记导出为Word、PPT等多种格式的文档。

**Paste URL into Selection**
选中文字后粘贴链接，可直接将选中的文字转化为超链接，快速关联外部网络内容。

**PDF++**
支持在Obsidian内边看PDF边批注。

**Templater**
功能强大的模板插件，支持识别代码实现多种自动化效果，比如自动生成创建时间、指定笔记保存路径等，可取代官方模板插件使用。
