
Niri 的快捷键是完全自定义的，都在 `~/.config/niri/config.kdl` 文件里配置。不过，我们通常会说有一份“默认”配置作为起点。

**最需要记住的一个快捷键是 `Mod+Shift+/`**，它能弹出热键列表，帮你随时查看所有当前的快捷键。

下面这些是常见场景的快捷操作，你可以参考一下，其中 `Mod` 键在 TTY 下默认是 `Super` (也就是 `Win` 键)。

### 启动与管理程序

*   **启动终端**：`Mod + T`（默认会启动 `alacritty`，你可以在配置里改成 `kitty`）。
*   **启动应用**：`Mod + D`（用 `fuzzel` 等启动器，如果你想用 `rofi`，记得改一下绑定）。
*   **关闭窗口**：`Mod + Q`。
*   **退出 Niri**：`Mod + Shift + E`。

### 窗口和工作区管理

Niri 独特的“滚动式平铺”体验主要靠下面这些操作：

*   **窗口/列导航**：
    *   焦点上移/下移：`Mod + Up` / `Down`
    *   焦点左移/右移（在列之间）：`Mod + Left` / `Right`
    *   移动窗口：加上 `Ctrl` 即可，比如 `Mod + Ctrl + Up/Down/Left/Right`。
*   **工作区导航**：
    *   上/下一个工作区：`Mod + Page_Up` / `Page_Down` 或 `Mod + I` / `U`。
    *   切换到指定工作区：`Mod + 1-9`。
    *   用鼠标滚轮切换：按住 `Mod` 并滚动滚轮。
*   **显示器焦点切换**：`Mod + Shift + 方向键`。

### 布局与窗口操作

*   **调整列宽**：`Mod + -/=`
*   **调整窗口高度**：`Mod + Shift + -/=`
*   **切换窗口浮动**：`Mod + V`
*   **切换全屏**：`Mod + F`
*   **打开/关闭总览**：用绑定的 `toggle-overview` 快捷键（新版 Niri 加入的功能，非常实用）。

以上这些只是默认配置的一个例子，所有按键的功能都可以根据自己的习惯在 `~/.config/niri/config.kdl` 里自由更改。想查看当前所有有效的快捷键，随时按下 `Mod+Shift+/` 就行。
