# 图片预览

## 概述

Yazi 支持在终端中预览图片，具体支持取决于终端模拟器和使用的图形协议。

## 支持的图形协议

| 协议 | 终端 | 说明 |
|------|------|------|
| Kitty Graphics | Kitty, WezTerm, Ghostty | 功能最完整 |
| Sixel | foot, Contour, mlterm | 兼容性较好 |
| iTerm2 Inline Images | iTerm2, WezTerm | macOS 常用 |
| Überzug | 任意 X11/Wayland 终端 | 需要额外安装 |
| Chafa | 任意终端 | 字符画形式预览 |

## 配置方式

### 方案 1：Kitty / WezTerm（推荐）

这些终端原生支持 Kitty 图形协议，无需额外配置。

```toml
# ~/.config/yazi/yazi.toml
[preview]
max_width  = 1000
max_height = 1000
```

### 方案 2：使用 Überzug++

适用于 X11 和 Wayland 下的任意终端。

```bash
# 安装 ueberzugpp
# Arch Linux
sudo pacman -S ueberzugpp

# 从源码编译
git clone https://github.com/jstkdng/ueberzugpp.git
cd ueberzugpp
cmake -B build
cmake --build build
sudo cmake --install build
```

配置 `yazi.toml`：

```toml
[preview]
# Überzug++ 会自动检测
```

### 方案 3：使用 Chafa（字符画）

适用于任意终端，但预览质量较低。

```bash
# 安装 chafa
sudo pacman -S chafa    # Arch Linux
brew install chafa      # macOS
```

```toml
# ~/.config/yazi/yazi.toml
[preview]
# chafa 作为后备方案
```

### 方案 4：使用 Sixel

需要终端支持 Sixel 协议。

```bash
# 安装依赖
sudo pacman -S libsixel
```

## 图片格式支持

| 格式 | 支持情况 |
|------|----------|
| JPEG | 完全支持 |
| PNG | 完全支持 |
| GIF | 支持（静态预览） |
| BMP | 完全支持 |
| WebP | 完全支持 |
| SVG | 取决于实现 |
| TIFF | 完全支持 |
| ICO | 完全支持 |

## 视频缩略图预览

需要安装 `ffmpegthumbnailer`：

```bash
# Arch Linux
sudo pacman -S ffmpegthumbnailer

# Ubuntu/Debian
sudo apt install ffmpegthumbnailer

# macOS
brew install ffmpegthumbnailer
```

配置 `yazi.toml`：

```toml
[[plugin.prepend_previewers]]
name = "*.mp4|*.mkv|*.avi|*.mov|*.webm"
run = "ffmpeg"
```

## PDF 预览

需要安装 `poppler-utils`：

```bash
# Arch Linux
sudo pacman -S poppler

# Ubuntu/Debian
sudo apt install poppler-utils

# macOS
brew install poppler
```

PDF 预览会自动将页面转换为图片显示。

## 压缩包预览

需要安装 `7z`：

```bash
# Arch Linux
sudo pacman -S p7zip

# Ubuntu/Debian
sudo apt install p7zip-full

# macOS
brew install p7zip
```

## JSON 预览

使用 `jq` 格式化 JSON 输出：

```bash
sudo pacman -S jq
```

## 代码预览

使用 `bat` 进行语法高亮预览：

```bash
sudo pacman -S bat
```

安装 bat 插件：

```bash
ya pack -a yazi-rs/plugins:bat
```

## 预览优化

### 调整预览质量

```toml
[preview]
# 图片质量（1-100）
image_quality = 75

# 预览延迟（毫秒）
image_delay = 30

# 最大文件大小限制（字节）
max_file_size = 10485760  # 10MB

# 文本预览最大行数
max_lines = 10000

# 是否显示行号
show_line_numbers = true

# Tab 宽度
tab_size = 4
```

### 缓存设置

```toml
[preview]
# 缓存目录大小（字节）
cache_size = 209715200  # 200MB
```

### 终端特定优化

#### Kitty

```ini
# ~/.config/kitty/kitty.conf
# 启用图形协议
allow_remote_control yes
```

#### WezTerm

```lua
-- ~/.config/wezterm/wezterm.lua
config.enable_kitty_graphics = true
```

#### Foot

```ini
# ~/.config/foot/foot.conf
[sixel]
# 启用 Sixel 支持
```

## 故障排除

### 图片不显示

1. 检查终端是否支持图形协议：
   ```bash
   echo -e "\e_Ga=T\e\\"
   # 如果显示乱码，终端可能不支持 Kitty 协议
   ```

2. 检查相关工具是否安装：
   ```bash
   which chafa ueberzugpp ffmpegthumbnailer
   ```

3. 查看 Yazi 日志：
   ```bash
   YAZI_LOG=debug yazi
   tail -f ~/.local/state/yazi/yazi.log
   ```

### 预览卡顿

- 减小 `max_width` 和 `max_height`
- 增加 `image_delay`
- 减小 `cache_size`
