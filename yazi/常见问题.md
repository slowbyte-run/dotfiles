# 常见问题

## 安装问题

### Q: 编译时出现错误

**错误**: `error: linker 'cc' not found`

**解决**:
```bash
# Arch Linux
sudo pacman -S base-devel

# Ubuntu/Debian
sudo apt install build-essential

# Fedora
sudo dnf groupinstall "Development Tools"
```

### Q: 找不到 yazi 命令

**解决**:
```bash
# 检查是否在 PATH 中
which yazi

# 如果使用 cargo 安装
export PATH="$HOME/.cargo/bin:$PATH"

# 添加到 shell 配置
echo 'export PATH="$HOME/.cargo/bin:$PATH"' >> ~/.bashrc
```

## 配置问题

### Q: 配置文件不生效

**解决**:
1. 检查配置文件路径是否正确：
   ```bash
   ls ~/.config/yazi/
   ```

2. 检查 TOML 语法：
   ```bash
   # 确保没有语法错误
   cat ~/.config/yazi/yazi.toml
   ```

3. 重启 Yazi 或运行：
   ```
   :config
   ```

### Q: 如何重置配置

**解决**:
```bash
# 备份现有配置
mv ~/.config/yazi ~/.config/yazi.bak

# 重新生成默认配置
ya init
```

## 图片预览问题

### Q: 图片不显示

**可能原因**:
1. 终端不支持图形协议
2. 缺少必要的依赖

**解决**:
```bash
# 检查终端类型
echo $TERM

# 安装 chafa 作为后备
sudo pacman -S chafa

# 查看日志
YAZI_LOG=debug yazi
tail -f ~/.local/state/yazi/yazi.log
```

### Q: 图片预览卡顿

**解决**:
```toml
# ~/.config/yazi/yazi.toml
[preview]
max_width  = 500
max_height = 500
image_delay = 50
```

### Q: Kitty 中图片不显示

**解决**:
```bash
# 检查 Kitty 版本
kitty --version

# 确保启用了远程控制
# ~/.config/kitty/kitty.conf
allow_remote_control yes
```

## 性能问题

### Q: 大目录加载慢

**解决**:
```toml
# ~/.config/yazi/yazi.toml
[manager]
# 限制扫描深度
scrolloff = 5

[preview]
# 限制预览大小
max_file_size = 5242880  # 5MB
```

### Q: 内存占用高

**解决**:
```toml
[preview]
# 减小缓存
cache_size = 10485760  # 10MB
```

## 键位问题

### Q: 快捷键冲突

**解决**:
```toml
# ~/.config/yazi/keymap.toml
# 使用 append_keymap 而不是 prepend_keymap
[[manager.append_keymap]]
on = ["j"]
run = "arrow 1"
```

### Q: 如何禁用某个快捷键

**解决**:
```toml
[[manager.prepend_keymap]]
on = ["某个按键"]
run = "noop"
```

## 文件操作问题

### Q: 删除文件时没有回收站

**解决**:
```bash
# 安装 trash-cli
sudo pacman -S trash-cli    # Arch Linux
sudo apt install trash-cli  # Ubuntu/Debian

# 或使用配置中的永久删除
# 在 yazi.toml 中配置
```

### Q: 粘贴时文件已存在

**解决**:
- 使用 `P`（大写）强制覆盖
- 或先重命名再粘贴

## 预览问题

### Q: 代码没有语法高亮

**解决**:
```bash
# 安装 bat
sudo pacman -S bat

# 安装 bat 插件
ya pack -a yazi-rs/plugins:bat
```

### Q: PDF 无法预览

**解决**:
```bash
# 安装 poppler-utils
sudo pacman -S poppler    # Arch Linux
sudo apt install poppler-utils  # Ubuntu/Debian
```

### Q: 视频没有缩略图

**解决**:
```bash
# 安装 ffmpegthumbnailer
sudo pacman -S ffmpegthumbnailer
```

## 常见配置错误

### TOML 语法错误

```toml
# 错误 - 缺少引号
sort_by = natural

# 正确
sort_by = "natural"
```

### 路径问题

```toml
# 错误 - 相对路径
editor = nvim

# 正确 - 使用变量
edit = [
    { run = '$EDITOR "$@"', block = true },
]
```

### 数组格式

```toml
# 错误
ratio = 1, 4, 3

# 正确
ratio = [1, 4, 3]
```

## 迁移问题

### 从 Ranger 迁移

1. 配置文件格式不同（Python vs TOML）
2. 键位绑定语法不同
3. 插件系统完全不同

### 从 LF 迁移

1. 配置从 Shell 脚本改为 TOML
2. 键位绑定语法不同

### 从 NNN 迁移

1. 配置从环境变量改为 TOML
2. 插件系统完全不同
