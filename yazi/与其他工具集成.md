# 与其他工具集成

## Zoxide 集成

Zoxide 是一个智能目录跳转工具，学习你的使用习惯。

### 安装

```bash
# 安装 zoxide
curl -sSfL https://raw.githubusercontent.com/ajeetdsouza/zoxide/main/install.sh | sh

# 或通过包管理器
sudo pacman -S zoxide    # Arch Linux
brew install zoxide      # macOS
```

### Shell 配置

```bash
# Bash (~/.bashrc)
eval "$(zoxide init bash)"

# Zsh (~/.zshrc)
eval "$(zoxide init zsh)"

# Fish (~/.config/fish/config.fish)
zoxide init fish | source
```

### 在 Yazi 中使用

| 按键 | 功能 |
|------|------|
| `z` | 使用 zoxide 跳转 |
| `Z` | 使用 zoxide 交互式选择 |

## fzf 集成

fzf 是一个通用的命令行模糊查找器。

### 安装

```bash
sudo pacman -S fzf    # Arch Linux
brew install fzf      # macOS
```

### 快捷键绑定

```toml
# ~/.config/yazi/keymap.toml

[[manager.prepend_keymap]]
on = ["s", "f"]
run = 'shell "fd --type f --hidden --exclude .git | fzf --preview \"bat --color=always --style=numbers {}\"" --confirm'
desc = "fzf 搜索文件"

[[manager.prepend_keymap]]
on = ["s", "d"]
run = 'shell "fd --type d --hidden --exclude .git | fzf" --confirm'
desc = "fzf 搜索目录"

[[manager.prepend_keymap]]
on = ["s", "g"]
run = 'shell "rg --color=always -n \"\" | fzf --delimiter : --preview \"bat --color=always {1} --highlight-line {2}\"" --confirm'
desc = "fzf 搜索内容"
```

## Lazygit 集成

Lazygit 是一个简单的终端 Git UI。

### 安装

```bash
sudo pacman -S lazygit    # Arch Linux
brew install lazygit      # macOS
```

### 在 Yazi 中使用

```toml
[[manager.prepend_keymap]]
on = ["g", "i"]
run = 'shell "lazygit" --block'
desc = "打开 Lazygit"
```

### 安装 lazygit 插件

```bash
ya pack -a yazi-rs/plugins:lazygit
```

## Tmux 集成

### 在 Tmux 中使用 Yazi

```bash
# 在 Tmux 中打开 Yazi
tmux new-session -s files 'yazi'

# 或在现有会话中
tmux new-window -n files 'yazi'
```

### Tmux 导航快捷键

```toml
# 在 Tmux 窗格间导航
[[manager.prepend_keymap]]
on = ["Ctrl+h"]
run = 'shell "tmux select-pane -L" --confirm'

[[manager.prepend_keymap]]
on = ["Ctrl+j"]
run = 'shell "tmux select-pane -D" --confirm'

[[manager.prepend_keymap]]
on = ["Ctrl+k"]
run = 'shell "tmux select-pane -U" --confirm'

[[manager.prepend_keymap]]
on = ["Ctrl+l"]
run = 'shell "tmux select-pane -R" --confirm'
```

## Neovim 集成

### 使用 Neovim 打开文件

```toml
[[manager.prepend_keymap]]
on = ["e"]
run = 'shell "nvim $@" --block'
desc = "用 Neovim 打开"
```

### 从 Neovim 打开 Yazi

在 Neovim 中使用 `:!yazi` 或配置快捷键：

```lua
-- ~/.config/nvim/lua/plugins/yazi.lua
vim.keymap.set('n', '<leader>y', ':!yazi<CR>', { noremap = true, silent = true })
```

## bat 集成

bat 是一个支持语法高亮的 cat 替代品。

### 安装

```bash
sudo pacman -S bat    # Arch Linux
brew install bat      # macOS
```

### 安装插件

```bash
ya pack -a yazi-rs/plugins:bat
```

配置 `yazi.toml`：

```toml
[[plugin.prepend_previewers]]
name = "*.py|*.rs|*.js|*.ts|*.go|*.c|*.cpp|*.java|*.rb|*.lua|*.sh"
run = "bat"

[[plugin.prepend_previewers]]
name = "*.json|*.yaml|*.yml|*.toml|*.xml"
run = "bat"
```
