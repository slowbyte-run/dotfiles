# 安装

## 系统要求

- 操作系统：Linux、macOS、Windows
- 终端模拟器：支持 Kitty 图形协议、Sixel 或 iTerm2 内联图像协议的终端（推荐）

## 安装方式

### Cargo（推荐）

```bash
cargo install --locked yazi-fm yazi-cli
```

### 包管理器

#### Arch Linux

```bash
# 官方仓库
sudo pacman -S yazi

# AUR（开发版）
yay -S yazi-git
```

#### macOS (Homebrew)

```bash
brew install yazi
```

#### NixOS / Nix

```bash
nix-env -iA nixpkgs.yazi
```

#### Ubuntu / Debian

```bash
# 需要从源码编译
sudo apt install cargo librust-jemalloc-sys-dev
cargo install --locked --features allocator yazi-fm yazi-cli
```

#### Fedora

```bash
sudo dnf install yazi
```

#### Void Linux

```bash
sudo xbps-install -S yazi
```

### 从源码编译

```bash
git clone https://github.com/sxyazi/yazi.git
cd yazi
cargo build --release
sudo cp target/release/yazi /usr/local/bin/
sudo cp target/release/ya /usr/local/bin/
```

| 依赖 | 用途 |

## 验证安装

```bash
yazi --version
```

## 配置目录

Yazi 的配置文件位于：

- **Linux/macOS**: `~/.config/yazi/`
- **Windows**: `%APPDATA%\yazi\\`

首次运行 Yazi 时，如果配置目录不存在会自动创建默认配置：

```bash
yazi
```

或手动生成配置：

```bash
ya init
```
