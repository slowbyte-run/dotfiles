# 基本操作

## 文件导航

### 移动光标

| 按键 | 功能 |
|------|------|
| `j` / `Down` | 向下移动一行 |
| `k` / `Up` | 向上移动一行 |
| `h` / `Left` | 返回父目录 |
| `l` / `Right` / `Enter` | 进入目录或打开文件 |
| `J` | 向下移动半页 |
| `K` | 向上移动半页 |
| `Ctrl+d` | 向下移动半页 |
| `Ctrl+u` | 向上移动半页 |
| `g g` | 跳转到顶部 |
| `G` | 跳转到底部 |

### 跳转

| 按键 | 功能 |
|------|------|
| `~` | 跳转到主目录 |
| `g h` | 跳转到主目录 |
| `g /` | 跳转到根目录 |
| `g c` | 跳转到 `~/.config` |
| `g d` | 跳转到 `~/Downloads` |
| `z` | 使用 zoxide 跳转 |
| `Z` | 使用 fzf 跳转 |
| `Ctrl+o` | 跳转到上一次访问的目录 |
| `Ctrl+i` | 跳转到下一次访问的目录（前进） |

### 目录历史

Yazi 会记录目录访问历史：

- `Ctrl+o` — 后退到上一个目录
- `Ctrl+i` — 前进到下一个目录

## 文件选择

### 单个选择

| 按键 | 功能 |
|------|------|
| `Space` | 切换当前文件的选中状态 |
| `v` | 反转所有选中文件 |

### 批量选择

| 按键 | 功能 |
|------|------|
| `Ctrl+a` | 全选 |
| `Ctrl+r` | 取消全选 |
| `y a` | 全选（yank all） |

### 按模式选择

在命令模式下使用 `:select` 命令，或使用过滤器：

```
:select *.txt    # 选择所有 .txt 文件
:select ^test    # 选择所有以 test 开头的文件
```

## 文件操作

### 复制 / 剪切 / 粘贴

| 按键 | 功能 |
|------|------|
| `y` | 复制选中文件（yank） |
| `x` | 剪切选中文件（cut） |
| `p` | 粘贴到当前目录 |
| `P` | 粘贴并强制覆盖 |
| `Ctrl+c` | 取消复制/剪切操作 |

### 删除

| 按键 | 功能 |
|------|------|
| `d` | 删除选中文件（移入回收站） |
| `D` | 永久删除（跳过回收站） |

删除确认后，文件会被移至系统回收站（需安装 `trash-cli`）。

### 创建与重命名

| 按键 | 功能 |
|------|------|
| `a` | 新建文件或目录 |
| `r` | 重命名当前文件 |

新建时：
- 输入 `filename.txt` — 创建文件
- 输入 `dirname/` — 创建目录（末尾加 `/`）

### 权限与属性

| 按键 | 功能 |
|------|------|
| `;` | 修改文件权限（chmod） |
| `:` | 打开命令行 |

## 文件打开

### 默认打开

| 按键 | 功能 |
|------|------|
| `l` / `Enter` | 使用默认程序打开文件 |
| `o` | 使用交互式选择器打开文件 |
| `O` | 使用交互式选择器在后台打开 |

### 自定义打开方式

Yazi 使用 `open` 命令（基于 `xdg-open` / `open`）打开文件。可以通过配置自定义打开方式：

编辑 `yazi.toml`：

```toml
[opener]
edit = [
    { run = 'nvim "$@"', block = true },
]
image = [
    { run = 'imv "$@"', block = false },
]
video = [
    { run = 'mpv "$@"', orphan = true },
]
pdf = [
    { run = 'zathura "$@"', block = false },
]
```

## 搜索

### 文件名搜索

| 按键 | 功能 |
|------|------|
| `/` | 向前搜索文件名 |
| `?` | 向后搜索文件名 |
| `n` | 下一个匹配 |
| `N` | 上一个匹配 |

### 过滤

| 按键 | 功能 |
|------|------|
| `f` | 过滤文件（仅显示匹配项） |
| `F` | 取消过滤 |

过滤支持 glob 模式，例如 `*.rs` 只显示 Rust 文件。

## 排序

通过 `:sort` 命令或在配置中设置默认排序：

| 命令 | 功能 |
|------|------|
| `:sort natural` | 自然排序（默认） |
| `:sort created` | 按创建时间排序 |
| `:sort modified` | 按修改时间排序 |
| `:sort extension` | 按扩展名排序 |
| `:sort size` | 按文件大小排序 |
| `:sort random` | 随机排序 |

使用 `:sort --reverse` 反转排序。

## 多标签页

| 按键 | 功能 |
|------|------|
| `t` | 在当前位置打开新标签页 |
| `1-9` | 切换到第 N 个标签页 |
| `[` | 切换到上一个标签页 |
| `]` | 切换到下一个标签页 |
| `Ctrl+c` | 关闭当前标签页 |
| `Tab` | 在当前标签页和上一个标签页之间切换 |

## 分屏 / 浮动窗口

Yazi 支持分屏和浮动窗口预览：

| 按键 | 功能 |
|------|------|
| `T` | 在新窗口中打开选中目录（类似 tmux） |

## 任务管理

| 按键 | 功能 |
|------|------|
| `w` | 显示任务管理器 |
| `W` | 以浮动窗口显示任务管理器 |

任务管理器中可以查看正在进行的文件操作（复制、移动、删除）的进度。

| 按键 | 功能 |
|------|------|
| `~` | 查看快捷键帮助 |
| `F1` | 打开 Yazi 文档 |
