# 插件系统

## 概述

Yazi 的插件系统基于 Lua 脚本，允许用户扩展功能。插件可以实现：

- 自定义文件预览
- 自定义文件信息显示
- 自定义命令
- 自动任务（自动解压、自动转换等）

## 插件目录

```
~/.config/yazi/plugins/
├── my-plugin.yazi/
│   ├── init.lua      # 插件入口
│   └── README.md     # 插件说明
└── another-plugin.yazi/
    └── init.lua
```

## 安装插件

### 使用 ya 包管理器

```bash
# 安装插件
ya pack -a <owner>/<repo>

# 例如安装 git 插件
ya pack -a yazi-rs/plugins:git

# 更新插件
ya pack -u

# 列出已安装插件
ya pack -l
```

### 手动安装

```bash
cd ~/.config/yazi/plugins/
git clone https://github.com/example/plugin.yazi.git
```

## 插件配置

在 `yazi.toml` 中配置插件：

```toml
# 预览插件
[[plugin.prepend_previewers]]
name = "*.md"
run = "bat"

# 文件信息插件
[[plugin.prepend_fetchers]]
name = "*"
run = "git"
```

## 常用插件

### 1. Git 集成

显示文件的 Git 状态（修改、新增、删除等）。

```bash
ya pack -a yazi-rs/plugins:git
```

配置 `yazi.toml`：

```toml
[[plugin.prepend_fetchers]]
name = "*"
run = "git"

[[plugin.prepend_fetchers]]
name = "*/"
run = "git"
```

### 2. 高亮预览

使用 bat 进行语法高亮预览。

```bash
ya pack -a yazi-rs/plugins:bat
```

```toml
[[plugin.prepend_previewers]]
name = "*.py|*.rs|*.js|*.ts|*.go|*.c|*.cpp|*.java"
run = "bat"

[[plugin.prepend_previewers]]
name = "*.md"
run = "bat"
```

### 3. 智能过滤

基于 mime 类型的智能文件过滤。

```bash
ya pack -a yazi-rs/plugins:smart-enter
```

### 4. 图片预览

增强的图片预览支持。

```bash
ya pack -a yazi-rs/plugins:max-preview
```

### 5. 自动解压

自动解压压缩文件预览。

```bash
ya pack -a yazi-rs/plugins:auto-unarchive
```

## 插件开发

### 基本结构

```lua
-- ~/.config/yazi/plugins/my-plugin.yazi/init.lua

local M = {}

function M:setup()
    -- 插件初始化
end

function M:entry(job)
    -- 插件主逻辑
    local target = job.files[1]
    if not target then
        return
    end

    -- 执行操作
    ya.emit("shell", {
        "echo 'Hello from my plugin!'",
        confirm = true,
    })
end

return M
```

### 插件 API

#### 事件系统

```lua
-- 监听事件
function M:setup()
    ps.sub("cd", function()
        -- 当目录改变时触发
    end)

    ps.sub("hover", function()
        -- 当光标移动时触发
    end)
end
```

#### 文件操作

```lua
-- 获取当前文件
local current = cx.active.current
local hovered = current.hovered

-- 获取选中的文件
local selected = cx.active.selected
```

#### 命令发送

```lua
-- 发送命令到 Yazi
ya.emit("cd", { "/path/to/dir" })
ya.emit("shell", { "command arg1 arg2" })
ya.emit("quit", {})
```

#### 用户界面

```lua
-- 显示通知
ya.notify {
    title = "My Plugin",
    content = "操作完成",
    level = "info",
}

-- 显示确认对话框
local confirm = ya.confirm {
    title = "确认",
    content = "是否继续？",
}
```

#### 文件系统

```lua
-- 读取文件
local content = ya.read_file("/path/to/file")

-- 写入文件
ya.write_file("/path/to/file", "content")

-- 列出目录
local entries = ya.list_dir("/path/to/dir")

-- 检查文件是否存在
local exists = ya.file_exists("/path/to/file")
```

### 预览器插件示例

```lua
-- 预览 Markdown 文件
local M = {}

function M:peek(job)
    local content = ya.read_file(job.file.url)
    if not content then
        return
    end

    -- 处理内容
    local lines = {}
    for line in content:gmatch("[^\r\n]+") do
        table.insert(lines, ui.Line(line))
    end

    -- 显示预览
    ya.preview_widgets(job, {
        ui.Text(lines):area(job.area),
    })
end

function M:seek(job)
    local h = cx.active.current.hovered
    if not h then
        return
    end
    ya.emit("peek", {
        math.max(0, cx.active.preview.skip + job.units),
    })
end

return M
```

### 获取器插件示例

```lua
-- 显示 Git 状态
local M = {}

function M:fetch(job)
    local paths = {}
    for _, file in ipairs(job.files) do
        table.insert(paths, tostring(file.url))
    end

    -- 执行 git status
    local output = Command("git")
        :arg("status", "--porcelain", "--no-renames")
        :arg(paths)
        :output()

    if not output then
        return
    end

    -- 解析结果
    local result = {}
    for line in output.stdout:gmatch("[^\r\n]+") do
        local status = line:sub(1, 2)
        local path = line:sub(4)
        result[path] = status
    end

    -- 返回结果
    return result
end

return M
```

### 自定义插件开发流程

1. 创建插件目录：
   ```bash
   mkdir -p ~/.config/yazi/plugins/my-plugin.yazi
   ```

2. 编写 `init.lua`

3. 在 `yazi.toml` 中配置插件

4. 重启 Yazi 测试

5. 调试时查看日志：
   ```bash
   # 启用日志
   YAZI_LOG=debug yazi

   # 查看日志
   tail -f ~/.local/state/yazi/yazi.log
   ```
