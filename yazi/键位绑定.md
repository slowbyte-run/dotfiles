# 键位绑定

## 概述

Yazi 的键位绑定通过 `keymap.toml` 配置文件定义，位于：

```
~/.config/yazi/keymap.toml
```

## 配置格式

键位绑定由以下部分组成：

```toml
[[manager.prepend_keymap]]
on   = ["按键"]         # 触发按键
run  = "命令"           # 执行的命令
desc = "描述"           # 可选描述
```

### 按键表示

| 类型 | 示例 |
|------|------|
| 普通键 | `"a"`, `"Enter"`, `"Space"` |
| Ctrl 组合 | `"Ctrl+a"`, `"Ctrl+Shift+t"` |
| Alt 组合 | `"Alt+j"`, `"Alt+Enter"` |
| 功能键 | `"F1"`, `"F2"` |
| 多键序列 | `["g", "g"]`（先按 g 再按 g） |

### 命令类型

- **字符串**：单个命令 `"quit"`
- **数组**：多个命令顺序执行 `["quit", "close"]`

## 自定义键位示例

### 用 Neovim 打开文件

```toml
[[manager.prepend_keymap]]
on = ["e"]
run = 'shell "nvim $@" --block'
desc = "用 Neovim 打开"
```

### 使用 fd 搜索文件

```toml
[[manager.prepend_keymap]]
on = ["s"]
run = 'shell "fd --type f --hidden --exclude .git | fzf" --confirm'
desc = "fd + fzf 搜索"
```

### 快速复制路径

```toml
[[manager.prepend_keymap]]
on = ["c", "p"]
run = 'shell "echo -n $@ | xclip -selection clipboard" --confirm'
desc = "复制文件路径到剪贴板"
```

### 批量重命名

```toml
[[manager.prepend_keymap]]
on = ["b"]
run = "rename --multiple"
desc = "批量重命名"
```

### 用 `$EDITOR` 打开

```toml
[[manager.prepend_keymap]]
on = ["e"]
run = 'shell "$EDITOR $@" --block'
desc = "用默认编辑器打开"
```

### 快速 cd 到文件所在目录

```toml
[[manager.prepend_keymap]]
on = ["g", "d"]
run = "cd ~/Documents"
desc = "跳转到 Documents"
```

### 解压文件

```toml
[[manager.prepend_keymap]]
on = ["E"]
run = 'shell "unar $@" --confirm'
desc = "解压文件"
```

## 按模式绑定

Yazi 支持不同的输入模式：

### 输入模式（输入框激活时）

```toml
[[input.prepend_keymap]]
on = ["Ctrl+w"]
run = "kill backward"
desc = "删除前一个词"
```

### 完成模式（自动补全时）

```toml
[[completion.prepend_keymap]]
on = ["Tab"]
run = "arrow 1"
desc = "下一个补全项"
```

### 帮助模式

```toml
[[help.prepend_keymap]]
on = ["q"]
run = "close"
desc = "关闭帮助"
```

## 键位冲突

如果定义了相同的按键，后定义的会覆盖先定义的。使用 `prepend_keymap` 在默认键位之前插入，使用 `append_keymap` 在之后插入。

## 查看当前键位

在 Yazi 中按 `~` 或 `F1` 可以查看当前所有键位绑定。
