# 快速入门

## 启动 Yazi

```bash
# 在当前目录启动
yazi

# 在指定目录启动
yazi /path/to/directory

# 打开指定文件（跳转到文件所在目录）
yazi /path/to/file.txt
```

## 界面布局

Yazi 默认采用三栏布局：

```
┌──────────┬──────────────┬──────────────┐
│  父目录   │   当前目录    │   预览窗口    │
│ (Parent) │  (Current)   │  (Preview)   │
│          │              │              │
│          │  file1.txt   │  [文件预览]   │
│          │  file2.rs    │              │
│          │  dir1/       │              │
│          │              │              │
├──────────┴──────────────┴──────────────┤
│ 状态栏 / 输入栏 / 任务栏                │
└────────────────────────────────────────┘
```

- **左侧**：父目录内容
- **中间**：当前工作目录
- **右侧**：选中文件/目录的预览
- **底部**：状态信息、命令输入、任务进度

## 基本导航

| 按键 | 功能 |
|------|------|
| `j` / `↓` | 向下移动 |
| `k` / `↑` | 向上移动 |
| `h` / `←` | 返回父目录 |
| `l` / `→` | 进入选中项（目录进入，文件打开） |
| `Enter` | 打开文件/进入目录 |

## 文件操作基础

| 按键 | 功能 |
|------|------|
| `y` | 复制（yank） |
| `x` | 剪切（cut） |
| `p` | 粘贴（paste） |
| `d` | 删除 |
| `r` | 重命名 |
| `a` | 新建文件/目录（末尾加 `/` 表示目录） |
| `Space` | 选中/取消选中当前文件 |

## 常用快捷键

| 按键 | 功能 |
|------|------|
| `q` | 退出 Yazi |
| `~` | 跳转到主目录 |
| `/` | 搜索 |
| `:` | 执行命令 |
| `.` | 切换隐藏文件显示 |
| `z` | 跳转到目录（使用 zoxide） |
| `Z` | 使用 fzf 跳转目录 |
| `Ctrl+t` | 打开/关闭任务管理器 |

## 退出后回到 Shell

Yazi 支持在退出时将当前目录传递给 Shell。在 Shell 配置中添加：

### Bash (`~/.bashrc`)

```bash
function y() {
	local tmp="$(mktemp -t "yazi-cwd.XXXXXX")" cwd
	yazi "$@" --cwd-file="$tmp"
	if cwd="$(command cat -- "$tmp")" && [ -n "$cwd" ] && [ "$cwd" != "$PWD" ]; then
		builtin cd -- "$cwd"
	fi
	rm -f -- "$tmp"
}
```

### Zsh (`~/.zshrc`)

```zsh
function y() {
	local tmp="$(mktemp -t "yazi-cwd.XXXXXX")" cwd
	yazi "$@" --cwd-file="$tmp"
	if cwd="$(command cat -- "$tmp")" && [ -n "$cwd" ] && [ "$cwd" != "$PWD" ]; then
		builtin cd -- "$cwd"
	fi
	rm -f -- "$tmp"
}
```

### Fish (`~/.config/fish/functions/y.fish`)

```fish
function y
	set tmp (mktemp -t "yazi-cwd.XXXXXX")
	yazi $argv --cwd-file="$tmp"
	if set cwd (command cat -- $tmp); and [ -n "$cwd" ]; and [ "$cwd" != "$PWD" ]
		builtin cd -- "$cwd"
	end
	rm -f -- "$tmp"
end
```

之后使用 `y` 命令代替 `yazi` 启动，退出后会自动切换到浏览的目录。
