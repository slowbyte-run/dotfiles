# 自定义命令

## 概述

Yazi 支持通过多种方式扩展命令：

1. Shell 命令 — 在命令行中执行 Shell 命令
2. Lua 插件 — 编写 Lua 插件实现复杂逻辑
3. 快捷键绑定 — 将命令绑定到快捷键

## Shell 命令

### 在 Yazi 中执行 Shell 命令

按 `:` 进入命令模式，然后输入 Shell 命令：

```bash
# 列出当前目录文件
:!ls -la

# 创建备份
:!cp $0 $0.bak

# 压缩选中的文件
:!tar -czvf archive.tar.gz $@
```

### 命令中的变量

| 变量 | 说明 |
|------|------|
| `$0` | 当前文件路径 |
| `$@` | 所有选中的文件路径 |
| `$*` | 所有选中的文件名 |
| `$1` | 第一个选中的文件路径 |
| `$n` | 第 n 个选中的文件路径 |

### 使用确认执行

```toml
[[manager.prepend_keymap]]
on = ["!"]
run = 'shell "$SHELL" --confirm'
desc = "打开 Shell"
```

## 常用自定义命令示例

### 1. 批量重命名

```toml
[[manager.prepend_keymap]]
on = ["b", "r"]
run = 'shell "echo $@ | xargs -I {} mv {} {}_backup" --confirm'
desc = "批量添加 _backup 后缀"
```

### 2. 计算文件哈希

```toml
[[manager.prepend_keymap]]
on = ["c", "h"]
run = 'shell "sha256sum $@ | tee /tmp/hash.txt && notify-send SHA256 $(head -c 16 /tmp/hash.txt)" --confirm'
desc = "计算 SHA256"
```

### 3. 压缩选中文件

```toml
[[manager.prepend_keymap]]
on = ["z", "p"]
run = 'shell "tar -czvf ${0:t}.tar.gz $@" --confirm'
desc = "压缩为 tar.gz"
```

### 4. 解压文件

```toml
[[manager.prepend_keymap]]
on = ["x", "p"]
run = 'shell "mkdir -p ${0:t:r} && tar -xzf $0 -C ${0:t:r}" --confirm'
desc = "解压 tar.gz"
```

### 5. 复制到剪贴板

```toml
# 复制文件路径
[[manager.prepend_keymap]]
on = ["c", "p"]
run = 'shell "echo -n $0 | xclip -selection clipboard" --confirm'
desc = "复制路径到剪贴板"

# 复制文件内容
[[manager.prepend_keymap]]
on = ["c", "c"]
run = 'shell "cat $0 | xclip -selection clipboard" --confirm'
desc = "复制内容到剪贴板"
```

### 6. 用浏览器打开

```toml
[[manager.prepend_keymap]]
on = ["g", "x"]
run = 'shell "xdg-open $0" --orphan'
desc = "用浏览器打开"
```

### 7. Git 操作

```toml
# Git 状态
[[manager.prepend_keymap]]
on = ["g", "s"]
run = 'shell "git status" --block'
desc = "Git 状态"

# Git diff
[[manager.prepend_keymap]]
on = ["g", "d"]
run = 'shell "git diff $0" --block'
desc = "Git diff"

# Git 添加
[[manager.prepend_keymap]]
on = ["g", "a"]
run = 'shell "git add $@" --confirm'
desc = "Git 添加"

# Git 提交
[[manager.prepend_keymap]]
on = ["g", "c"]
run = 'shell "git commit -m \"update\"" --confirm'
desc = "Git 提交"
```

### 8. 查找重复文件

```toml
[[manager.prepend_keymap]]
on = ["f", "d"]
run = 'shell "fdupes -r ." --block'
desc = "查找重复文件"
```

### 9. 图片处理

```toml
# 调整图片大小
[[manager.prepend_keymap]]
on = ["i", "r"]
run = 'shell "convert $0 -resize 800x600 ${0:r}_resized.${0:e}" --confirm'
desc = "调整图片大小"

# 转换图片格式
[[manager.prepend_keymap]]
on = ["i", "c"]
run = 'shell "convert $0 ${0:r}.webp" --confirm'
desc = "转换为 WebP"
```

### 10. 文件同步

```toml
[[manager.prepend_keymap]]
on = ["s", "y"]
run = 'shell "rsync -avz $@ user@host:/backup/" --confirm'
desc = "Rsync 到远程"
```

## 复合命令

使用 `&&` 或 `;` 连接多个命令：

```toml
[[manager.prepend_keymap]]
on = ["x", "x"]
run = [
    'shell "mkdir -p /tmp/backup && cp -r $@ /tmp/backup/" --confirm',
    'shell "echo 备份完成" --confirm',
]
desc = "备份并确认"
```

## 使用外部工具

### fzf 集成

```toml
[[manager.prepend_keymap]]
on = ["s", "f"]
run = 'shell "fd --type f | fzf --preview \"bat --color=always {}\"" --confirm'
desc = "fzf 搜索文件"
```

### ripgrep 集成

```toml
[[manager.prepend_keymap]]
on = ["s", "g"]
run = 'shell "rg --color=always -n \"$1\"" --confirm'
desc = "ripgrep 搜索内容"
```

### jq 处理 JSON

```toml
[[manager.prepend_keymap]]
on = ["j", "q"]
run = 'shell "jq . $0 | $EDITOR -" --block'
desc = "用 jq 格式化 JSON"
```

## 条件执行

在 Lua 中实现条件逻辑：

```lua
-- ~/.config/yazi/init.lua

function M:setup()
    -- 根据文件类型执行不同命令
    ps.sub("open", function()
        local h = cx.active.current.hovered
        if not h then return end

        local ext = h.url:ext()
        if ext == "md" then
            ya.emit("shell", { "glow $0", block = true })
        elseif ext == "png" or ext == "jpg" then
            ya.emit("shell", { "imv $0", orphan = true })
        end
    end)
end
```

## 环境变量

在命令中使用环境变量：

```toml
[[manager.prepend_keymap]]
on = ["e", "d"]
run = 'shell "$EDITOR $0" --block'
desc = "用 $EDITOR 打开"

[[manager.prepend_keymap]]
on = ["b", "r"]
run = 'shell "$BROWSER $0" --orphan'
desc = "用 $BROWSER 打开"
```

## 命令输出处理

将命令输出重定向：

```toml
[[manager.prepend_keymap]]
on = ["o", "p"]
run = 'shell "find . -name \"*.pdf\" -print0 | xargs -0 -I {} echo {}" --block'
desc = "列出所有 PDF"
```

## 错误处理

使用 `--confirm` 确保命令成功执行：

```toml
[[manager.prepend_keymap]]
on = ["d", "c"]
run = 'shell "docker compose down && docker compose up -d" --confirm'
desc = "Docker Compose 重启"
```
