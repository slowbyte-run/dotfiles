# 主题定制

## 概述

Yazi 的主题通过 `theme.toml` 配置，支持自定义颜色、图标和样式。

配置文件路径：

```
~/.config/yazi/theme.toml
```

## 颜色系统

### 支持的颜色格式

```toml
# 命名颜色
fg = "red"
bg = "blue"

# 16 色
fg = "lightred"
bg = "darkblue"

# 256 色
fg = 123

# RGB 真彩色
fg = "#ff8800"
bg = "#282828"

# 无颜色
fg = "reset"
```

### 常用颜色名

```
black, red, green, yellow, blue, magenta, cyan, white
lightblack (gray), lightred, lightgreen, lightyellow
lightblue, lightmagenta, lightcyan, lightwhite
```

## 主题结构

### 整体布局

```toml
# ============================================
# 管理器样式
# ============================================

# 分隔线
[separator]
symbol = "│"

# 边框
[border]
symbol = "│"
style  = { fg = "#505050" }

# 表头
[header]
style = { fg = "#b8b8b8", bg = "#303030" }

# 文件名样式
[filetype]
# 具体文件类型见下文

# ============================================
# 状态栏
# ============================================

[status]
separator = { open = "", close = "" }
separator_style = { fg = "#606060", bg = "#202020" }

[status.mode_normal]
style = { fg = "#282828", bg = "#7aa2f7", bold = true }

[status.mode_select]
style = { fg = "#282828", bg = "#f7768e", bold = true }

[status.mode_unset]
style = { fg = "#282828", bg = "#e0af68", bold = true }

# 标签页
[tab]
active   = { fg = "white", bg = "#303030" }
inactive = { fg = "#808080", bg = "#1a1a1a" }

# ============================================
# 预览窗口
# ============================================

[preview]
# 语法高亮主题
syntect_theme = ""

# ============================================
# 输入框 / 帮助
# ============================================

[input]
border   = { fg = "#505050" }
title    = { fg = "#c0c0c0" }
value    = { fg = "white" }
selected = { bg = "#404040" }

[completion]
border   = { fg = "#505050" }
active   = { fg = "white", bg = "#404040" }
inactive = { fg = "#808080" }
```

## 预设风格（Flavors）

Yazi 提供预设风格，可以从社区获取：

### 安装风格

```bash
# 创建 flavors 目录
mkdir -p ~/.config/yazi/flavors/

# 克隆风格仓库
git clone https://github.com/yazi-rs/flavors.git /tmp/yazi-flavors
cp -r /tmp/yazi-flavors/* ~/.config/yazi/flavors/
```

### 使用风格

在 `theme.toml` 中引用：

```toml
[flavor]
use = "catppuccin-mocha"
```

### 常用风格

- `catppuccin-mocha` — Catppuccin Mocha 主题
- `catppuccin-latte` — Catppuccin Latte 主题
- `dracula` — Dracula 主题
- `gruvbox-dark` — Gruvbox Dark 主题
- `nord` — Nord 主题
- `tokyonight` — Tokyo Night 主题
- `everforest` — Everforest 主题
- `kanagawa` — Kanagawa 主题

## 完整主题示例

### Catppuccin Mocha 风格

```toml
[flavor]
use = "catppuccin-mocha"

# 如果没有安装 flavor，手动配置：
[status]
separator = { open = "", close = "" }

[status.mode_normal]
style = { fg = "#1e1e2e", bg = "#cba6f7", bold = true }

[status.mode_select]
style = { fg = "#1e1e2e", bg = "#f38ba8", bold = true }

[status.mode_unset]
style = { fg = "#1e1e2e", bg = "#fab387", bold = true }

[filetype]
rules = [
    { name = "*", fg = "#cdd6f4" },
    { name = "*/", fg = "#89b4fa" },
]
```

## 语法高亮主题

预览窗口的语法高亮通过 `syntect_theme` 配置：

```toml
[preview]
# 使用内置主题
syntect_theme = "base16-ocean.dark"

# 或使用自定义主题文件
syntect_theme = "~/.config/yazi/themes/monokai.tmTheme"
```

### 可用主题

```
base16-ocean.dark
base16-ocean.light
base16-eighties.dark
base16-mocha.dark
InspiredGitHub
Solarized (dark)
Solarized (light)
```

## 自定义状态栏

通过 Lua 脚本可以自定义状态栏内容：

```lua
-- ~/.config/yazi/init.lua

function Status:mode()
    local mode = tostring(self._tab.mode):upper()
    if mode == "NORMAL" then
        return ui.Span(" " .. mode .. " "):style(THEME.status.mode_normal)
    elseif mode == "SELECT" then
        return ui.Span(" " .. mode .. " "):style(THEME.status.mode_select)
    else
        return ui.Span(" " .. mode .. " "):style(THEME.status.mode_unset)
    end
end

function Status:size()
    local h = cx.active.current.hovered
    if not h then
        return ui.Span("")
    end
    return ui.Span(" " .. ya.readable_size(h.cha.len) .. " "):fg("#a0a0a0")
end
```
