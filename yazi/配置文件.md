# 配置文件

## 配置目录结构

```
~/.config/yazi/
├── yazi.toml        # 主配置文件
├── keymap.toml      # 键位绑定
├── theme.toml       # 主题配置
├── plugins/         # 插件目录
├── flavors/         # 预设风格目录
└── init.lua         # Lua 初始化脚本
```

## 主配置文件 yazi.toml

### 完整示例

```toml
# ============================================
# 管理器设置
# ============================================
[manager]
# 排序方式： "alphabetical", "created", "modified", "natural", "size", "extension", "random"
sort_by        = "natural"
# 排序方向： true = 降序
sort_reverse   = false
# 是否显示隐藏文件
show_hidden    = false
# 是否显示目录优先
sort_dir_first = true
# 光标样式： "block", "beam", "underline"
cursor_style   = "block"
# 布局比例 [父目录, 当前目录, 预览窗口]
ratio          = [1, 4, 3]
# 边框类型： "all", "top", "bottom", "left", "right", "none"
linemode       = "size"
# 目录最大扫描深度
scrolloff      = 5
# 文件限制
max_width      = 600
max_height     = 900

# ============================================
# 预览设置
# ============================================
[preview]
# 预览窗口最大宽度
max_width  = 600
# 预览窗口最大高度
max_height = 900
# 缓存大小（字节）
cache_size = 20971520  # 20MB
# 图片缓存大小
image_delay = 30
# 是否自动预览
wrap        = "no"
# 预览行数限制
tab_size    = 2
# 文本预览最大字节数
max_repo_size = 10485760  # 10MB

# ============================================
# 打开方式设置
# ============================================
[opener]
# 编辑器
edit = [
    { run = 'nvim "$@"', block = true, desc = "Neovim" },
]
# 图片查看
image = [
    { run = 'feh "$@"', orphan = true, desc = "feh" },
]
# 视频播放
video = [
    { run = 'mpv "$@"', orphan = true, desc = "mpv" },
]
# PDF 阅读
pdf = [
    { run = 'zathura "$@"', orphan = true, desc = "zathura" },
]
# 音频播放
audio = [
    { run = 'mpv "$@"', orphan = true, desc = "mpv" },
]
# 文件夹
folder = [
    { run = '$EDITOR "$@"', desc = "编辑器" },
]
# 压缩文件
archive = [
    { run = 'unar "$1"', desc = "解压" },
]
# 文本文件
text = [
    { run = '$EDITOR "$@"', block = true, desc = "编辑器" },
]
# 回退
fallback = [
    { run = 'xdg-open "$@"', orphan = true, desc = "xdg-open" },
]

# ============================================
# 文件类型关联
# ============================================
[[open.rules]]
name = "*.jpg|*.jpeg|*.png|*.gif|*.bmp|*.webp|*.svg"
use = ["image"]

[[open.rules]]
name = "*.mp4|*.mkv|*.avi|*.mov|*.webm"
use = ["video"]

[[open.rules]]
name = "*.mp3|*.flac|*.wav|*.ogg|*.m4a"
use = ["audio"]

[[open.rules]]
name = "*.pdf"
use = ["pdf"]

[[open.rules]]
name = "*.zip|*.tar|*.gz|*.xz|*.7z|*.rar"
use = ["archive"]

[[open.rules]]
name = "*/"
use = ["folder"]

# 条件规则
[[open.rules]]
name = "*"
use = ["edit", "open"]

# ============================================
# 提取器（预览用）
# ============================================
[plugin]
preloaders = [
    # 预加载规则
]

fetchers = [
    # 文件信息获取规则
]

# ============================================
# 日志
# ============================================
[log]
enabled = false
```

### 管理器详解

| 选项 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `sort_by` | string | `"natural"` | 排序方式 |
| `sort_reverse` | bool | `false` | 反转排序 |
| `show_hidden` | bool | `false` | 显示隐藏文件 |
| `sort_dir_first` | bool | `true` | 目录排在前面 |
| `linemode` | string | `"size"` | 行信息模式 |
| `ratio` | array | `[1, 4, 3]` | 三栏比例 |
| `scrolloff` | number | `5` | 光标上下保留行数 |

#### linemode 可选值

- `"size"` — 显示文件大小
- `"permissions"` — 显示权限
- `"mtime"` — 显示修改时间
- `"atime"` — 显示访问时间
- `"ctime"` — 显示创建时间
- `"owner"` — 显示所有者
- `"none"` — 不显示额外信息

### 预览设置详解

| 选项 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `max_width` | number | `600` | 预览最大宽度 |
| `max_height` | number | `900` | 预览最大高度 |
| `cache_size` | number | `20971520` | 缓存大小（字节） |
| `wrap` | string | `"no"` | 文本换行：`"no"`, `"yes"`, `"auto"` |
| `tab_size` | number | `2` | Tab 宽度 |

### 打开方式配置

每个 opener 条目支持以下选项：

| 选项 | 类型 | 说明 |
|------|------|------|
| `run` | string | 执行的命令，`$@` 为选中文件列表 |
| `block` | bool | 是否阻塞（等待命令结束） |
| `orphan` | bool | 是否独立进程（Yazi 退出后继续运行） |
| `desc` | string | 描述 |

命令中的变量：
- `$@` — 所有选中的文件路径
- `$*` — 所有选中的文件名
- `$1` — 第一个文件路径
- `$0` — 当前文件路径

### 规则匹配

`[[open.rules]]` 支持：

```toml
[[open.rules]]
name = "*.ext"          # glob 匹配文件名
mime = "text/*"         # MIME 类型匹配
use = ["opener1", "opener2"]  # 使用的打开器列表
```

## Lua 初始化脚本 init.lua

`init.lua` 用于执行自定义 Lua 代码：

```lua
-- ~/.config/yazi/init.lua

-- 示例：自定义函数
function Status:owner()
    local h = cx.active.current.hovered
    if h == nil or ya.target_family() ~= "unix" then
        return ui.Line {}
    end

    return ui.Line {
        ui.Span(ya.user_name(h.cha.uid) or tostring(h.cha.uid)):fg("magenta"),
        ui.Span(":"):fg("white"),
        ui.Span(ya.group_name(h.cha.gid) or tostring(h.cha.gid)):fg("magenta"),
        ui.Span(" "),
    }
end
```

## 环境变量

| 变量 | 说明 |
|------|------|
| `YAZI_CONFIG_HOME` | 自定义配置目录 |
| `EDITOR` | 默认编辑器 |
| `SHELL` | 默认 Shell |

## 配置重载

在 Yazi 中运行以下命令重载配置：

```
:config
```

或按快捷键重新加载。
